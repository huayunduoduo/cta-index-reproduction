# 三指数时序CTA：华泰方法的完整计算复现

对象：000300.XSHG、000001.XSHG、399006.XSHE。依据华泰证券2026-06-10《时序CTA方法论综述：市场状态、开仓信号与退出机制》第12—16页实证规则。

**指数代理实验，不是原文三只ETF数字复现。作者未公开代码及若干定义，本仓库公开全部补充假设；不能承诺与作者逐笔一致。**

## 完整计算约定

没有quick模式。每个可估计日期执行联合高斯AR(1)-GARCH(1,1)极大似然；1000条递归标准残差Bootstrap路径，每条都重新联合估计AR和GARCH；失败的Bootstrap数值优化会追加抽样以获得1000条收敛复制，额外次数记录。无法完成1000条时抛出错误，不生成“完成”报告。rho的t值使用联合观测信息矩阵，不是固定方差WLS。

使用C++17精确梯度与BFGS加速计算，Python负责数据与交易账本。加速没有省略GARCH重估，也没有把Bootstrap换成OLS或固定方差近似。数值MLE不保证找到全局最优；边界附近信息矩阵可能非正定，rho_t记为空，状态仍按原文另一个波动率条件评价。

本研究没有监督学习模型的训练/验证标签。这里的“训练”是每个日期仅用过去滚动窗口进行参数估计与重采样，不是全样本挑选收益最高参数。1000次重采样也不等于1000个独立市场历史样本。

## 本地部署

Python 3.12、C++17编译器g++。Linux可用系统g++；Windows需安装提供g++的MinGW-w64工具链并将bin加入PATH，先确认`g++ --version`可运行。VS Code只是编辑器，不自带编译器。当前核心计算在Linux Python3.12/g++验证，Windows脚本未实际运行。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe run.py --daily data/81_etf_data_1d.xlsx --minute data/81_etf_data_1m.csv --workers 6
.\.venv\Scripts\python.exe report.py
```

两份用户原数据复制到data，文件名按命令重命名即可。原文件带(1)时，也可以用引号指定原路径。Linux使用python3替代`.venv`解释器路径。第一次调用自动编译native/model.cpp；可提前运行`python -c "from model import library;library()"`。编译错误不会静默回退到简化算法。

运行完输出`results/full/manifest.json`的status必须为COMPLETED。研究窗口2020-01-01至2026-05-31，之前数据预热；2026年6月以后的原数据不参与估计与绩效。运行会覆盖同一out目录，保留旧实验请使用不同`--out`。

## 必须理解的执行口径

- t日收盘信号，t+1开盘执行。入场当天不运行退出分支；已持仓日不再开新仓；当天止损后最早下一交易日再入场。
- 止损价盘前冻结，盘中不利用本分钟最高价修改后再用该分钟最低价回看触发；日间跳空按开盘，分钟跳空按该分钟开盘处理。
- 盘前止损价只朝有利方向移动，不因ATR扩大而放宽。
- 趋势仓采用ATR；震荡仓RSI收盘确认退出、次日开盘。RSI退出时点原文没有完整明确，属于实现假设。
- 单边滑点1‰、佣金1‰，分别改变成交价格和现金费用。原文费用句可能有合计/分别歧义；这里固定采用分别计算，未根据结果择优。
- 入场按当时净权益100%原始名义价格计算份额，随后固定份额直到退出，不每天自动恢复100%权重；指数可多空只是合成研究账户，没有指数实盘、ETF借券或融资假设。
- 末日按收盘强平并收费，交易中标记terminal_liquidation。净值峰值包括初始资本1；年化按252交易日。
